# Гарик · AI Persona Lab

Один ИИ-персонаж с характером, голосом и собственной жизнью. Учебный проект
трека 2 AI Persona Lab, осень 2026.

Гарик — пришелец, который прилетел на Землю пожить подешевле и задержался почти
на три тысячи лет. Сейчас живёт в России над круглосуточной шаурмичной.
Язвительный, самоуверенный, азартный: замечает чужую дурь, затевает свою
и травит байки. Огромный опыт не мешает ему увлекаться ерундой.

![Гарик — утверждённый облик](resources/character/garik-final.png)

## Что готово

- Русская личность v11, биография и утверждённая внешность.
- Контекстная речь с памятью просьбы «без мата»; старые режимы сохранены.
- Отдельные словари и сборка цельного промпта из файлов.
- Рабочее место Гарика по шаблону организаторов.
- Локальный исполнитель: события, гибридная память, личный дневник и восстановление.
- Разговор и самостоятельные пробуждения в одном ограниченном цикле на Mac.
- Отмена устаревших ответов, отдельные сообщения с паузами и нативный веб-поиск.
- Фоновый процесс и защищённая localhost-панель: чат, занятия, контекст и фактический usage.
- Постоянный диалог Codex и отдельное исследование с ограниченным возвратом фактов.
- Изолированная лаборатория мира: обстоятельства, выбор, последствия и пульт с ползунками. Есть ограниченные прогоны, память собственных затей и опциональный самостоятельный выбор местных черновиков канала; художественное качество ещё оценивается.
- Локальное подключение Telegram: ввод токена BotFather, проверка канала/обсуждения, приём комментариев и явная техническая проверка доставки. Связь с автономной жизнью ещё не включена.
- Тестовые разговоры, точные снимки промптов и разборы.

Новая личность проверена в 55 фактических решениях Codex на тестовых беседах.
Приветствия, отказы, исправления фактов и контекст речи стали устойчивее в этих
сценах; консультантская привычка полностью не устранена; длинная связность требует наблюдения.
[Разбор с ограничениями](docs/character-test-2026-10-11.md). Технические проверки
исполнителя сами по себе не доказывают качество автономного поведения.
[Реальные ожидания, перезапуск, поиск и доставка](docs/runtime-verification-2026-10-11.md)
проверены отдельно на изолированных тестовых данных.
Транспорт Telegram проверяется отдельно от персонажа: [подключение и ограничения](docs/telegram-connection.md).
Голос, видео и облачное развёртывание ещё не подключены.

## Запустить локально

```sh
python3 -m persona_runtime chat
```

Нужны Python и авторизованный Codex CLI; модель работает удалённо.
Для гибридной памяти используется локальное окружение Python 3.12
([установка](docs/runtime-memory.md)).
На Mac можно открыть `start-garik.command`. Личный чат по умолчанию выбирает
речь по ситуации; мат допустим, просьба говорить без мата сохраняется.
Для принудительно чистого разговора добавьте `--register non-obscene`.
Самостоятельные пробуждения ограничены тремя за час; `/pause` ставит их на паузу.
`garik panel` открывает браузерную панель и отдельный ограниченный фоновый процесс.
Закрытие вкладки его не останавливает; сон Mac приостанавливает выполнение.
[Запуск, остановка, расход и ограничения панели](docs/runtime-panel.md).
[Постоянные диалоги: проверки и ограничения](docs/runtime-sessions.md).
[Отдельная модель мира и пульт](docs/world-lab.md) пока запускаются отдельно от рабочего Гарика.
[Инструкция: запуск, память, восстановление и ограничения](docs/local-runtime.md).

## Локальная проверка

Нужен Python 3, дополнительных библиотек нет. Из корня проекта:

```sh
python3 tools/check.py
python3 tools/test_prompt_composition.py
python3 tools/compose_persona.py garik --register non-obscene-chat
```

Последняя команда печатает промпт; модель не вызывает.
[Карта файлов и утилит](docs/code-map.md).
