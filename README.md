# Гарик · AI Persona Lab

Один ИИ-персонаж с характером, голосом и собственной жизнью. Учебный проект
трека 2 AI Persona Lab, осень 2026.

Гарик — пришелец, который прилетел на Землю пожить подешевле и задержался почти
на три тысячи лет. Сейчас живёт в России над круглосуточной шаурмичной.
Язвительный, самоуверенный, азартный: замечает чужую дурь, затевает свою
и травит байки. Огромный опыт не мешает ему увлекаться ерундой.

![Гарик — утверждённый облик](resources/character/garik-final.png)

## Что готово

- Русская личность v10, биография и утверждённая внешность.
- Два речевых режима: без мата и свободная беседа с разрешённым матом.
- Отдельные словари и сборка цельного промпта из файлов.
- Рабочее место Гарика по шаблону организаторов, без выдуманной памяти о реальных сессиях.
- Тестовые разговоры, точные снимки промптов и разборы.

Промпт проверен в чатах. Последние две итерации дали 23 ответа:
лучше связность событий, отказы и реакция на собеседника; инициатива пока
нестабильна. Это проверка текстового общения. Голос, Telegram, видео,
исполнитель действий и автономный цикл ещё не подключены.

## Локальная проверка

Нужен Python 3, дополнительных библиотек нет. Из корня проекта:

```sh
python3 tools/check.py
python3 tools/test_prompt_composition.py
python3 tools/compose_persona.py garik --register non-obscene-chat
```

Последняя команда печатает промпт; модель не вызывает.
[Карта файлов и утилит](docs/code-map.md).
