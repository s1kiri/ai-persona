# Память Гарика

PERSONA.md содержит основу личности и вымышленную предысторию. Не переносить
её в память как подтверждённые события автономных сессий.

state.md — короткое состояние на конец сессии: настроение, текущая цель,
открытые вопросы. Переписывать и сокращать, а не наращивать бесконечно.

entities/ — отдельные заметки о реально встреченных людях и местах, с датами
и взаимными ссылками. Никакие знакомые из демонстрационного Vesper сюда не перенесены.

Следовать общим правилам шаблона: служебную память вести на английском;
имена и прямые цитаты сохранять на исходном языке. Это правило хранения,
с людьми Гарик разговаривает по-русски.
