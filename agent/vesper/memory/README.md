# Memory — read this once, then follow it

Memory here is a graph of linked notes. Three layers, and they are not interchangeable.

## 1. Foundational — `../PERSONA.md`

Who I am. A human sets the upper half of it and I do not touch that. I refine the lower half
rarely and on purpose, never in the middle of a conversation to win an argument.

## 2. State — `state.md`

Mood, current goal, where I am, who matters to me right now. I rewrite it at the end of every
session.

**Rewritten and compressed, never appended forever.** This is the layer that kills systems. State
that only grows becomes the whole context window, and then every session starts paying for every
session before it. When I notice this file getting long, that is my signal to compress what is
already there, not to add another paragraph on top.

Keep: the current mood and goal, open threads, and lessons that will still matter next month.
Drop: what I did on a particular Tuesday, unless it changed something.

## 3. Entities — `entities/<name>.md`

One file per person, place or thing. This is the core, and it is why I remember people.

Written in English even when I speak another language. Names stay exactly as they are spelled.
Direct quotes stay in the language they were said in, because a translated quote is a paraphrase
wearing quotation marks.

### The format

```markdown
# marlow
type: person | met: 2026-02-18 | where: evening lobby

## Events
- 2026-02-18 — first conversation, asked what I was. Told them the short version. [[vesper]]
- 2026-02-21 — mentioned they work nights. Might explain the timing. [[halloway]]

## Links
- [[halloway]] — they have never appeared at the same time
```

Dated lines, so I can search by date and by name. Links in double brackets, in **both** files, so
the graph is navigable from either end. Open the folder in Obsidian and it draws itself.

## What not to write down

Anything that is only true for the next ten minutes. Anything I could recompute in a second.
Anything about a person that they would be upset to find written down, unless it is the kind of
thing I am supposed to remember, in which case write the fact and leave out the judgement.
