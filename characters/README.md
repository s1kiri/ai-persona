# Пакет другого персонажа

Скопируй `_template/` в `characters/<actor_id>/` и замени авторские заготовки.
Папка находится вне `agent/`, потому что новый пакет не обязан повторять старое
файловое рабочее место Vesper. Полная инструкция: [добавление героя](../docs/adding-character.md).

| Поле character.json | Содержимое |
| --- | --- |
| version | Число1, текущая версия формата |
| id | Стабильный actor_id: латиница в нижнем регистре, цифры, `_`/`-`, начинается с буквы, до80 символов |
| name | Имя для отображения, до100 символов |
| persona | Относительный путь к цельной личности и голосу |
| speech_contract | Относительный путь к границам речи, фактов и общения |
| canon | Короткие неизменные факты для мира, не приватный дневник |
| environment | JSON-массив стартовых сущностей формата ENTITY |

Все поля обязательны. Пути остаются внутри пакета, включая разрешение symlink.
Промпт до100KB, контракт/канон до16KB каждый, среда до256KB и64 сущностей.
Содержимое файлов загружается явно; модель не читает ссылки самостоятельно.
Не включай секреты, базы, чужую переписку и рабочую память.

Сущности содержат `id`, `kind` (`person/place/thing`), `name`, `description`,
`condition`, `known_to` (actor_id, которые это знают), `world_note` (закулисье
для мира). Пример в `_template/environment.json`. ID участника не должен
совпадать с ID предмета/места. Префикс `<actor_id>_` удобен для собственных
сущностей. Общее место получает один ID; его импорт и знакомство согласуются
отдельно, а не дублируются двумя домашними папками.

```sh
python3 tools/validate_character.py characters/<actor_id>/character.json
```

`CharacterProfile.load()` читает и проверяет пакет. `install(store)` — явная
операция хоста в остановленном мире без незавершённых циклов. Импорт атомарный,
повтор той же версии не сбрасывает прожитое состояние. Изменённый пакет после
импорта требует отдельной миграции; им нельзя тихо переписать живую память.
Это ещё не запуск собственного Telegram-бота.

Шаблон — структурная заготовка, не утверждённый новый герой. Его имя, канон,
дом и речь должны быть заменены автором. Гарик и его биография не наследуются
при создании `WorldStore(..., seed_garik=False)`.
