# Гарик — переносимый публичный профиль

Пакет для общего хоста с Аркадием. Голос скопирован без редактирования из
`resources/character/garik-prompt-contextual.md`; канон и домашние места —
из исходной инициализации мира. Добавлена согласованная общая предыстория
дружбы с Аркадием Кедровым; она не назначает сегодняшнюю встречу.

Это публичная версия. Рабочая приватная личность Гарика на компьютере Кирилла
может отличаться. Для продолжения того запуска нужно перенести его собственный
пакет и базу, не заменяя живой голос этим экспортом. Приватные файлы хранить
в `.local/`, не коммитить. Модель без `runtime` сохраняет общий default хоста;
изменение модели Аркадия не переключает Гарика автоматически.

Общий запуск и миграция описаны в `docs/shared-life.md`. Токены, каналы,
реальная переписка и фото сюда не входят. Исходный портрет остаётся
`resources/character/garik-final.png`; пакет не выдумывает новый облик.
