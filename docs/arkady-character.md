# Аркадий: перенос, проверка и запуск

16 октября 2026. Пакет: [characters/arkady](../characters/arkady/README.md).
Основа ветки — `14738df` (`main` при начале переноса).
Контракт переноса — [adding-character.md](adding-character.md).

## Что перенесено

Главный источник — `agent/resources/arkadiy.md` проекта Аркадия.
Личность, словари обоих регистров и авторские примеры перенесены дословно
до последнего раздела контекста. Последний раздел обобщён для разных
ситуаций запуска; подробности и SHA-256 источника — в README пакета.
Исходный проект сохранён без изменений.

Старые файлы рабочего места содержат более конкретный канон, который
расходится с выбранным главным источником. Эти детали не смешаны с пакетом:
содержимое контейнера и подробности первой встречи остаются неопределёнными.
Тайные желания не включены в канон мира. Секреты, переписки, цели, дневник,
inbox/outbox и инструкции файлового исполнителя не перенесены.

## Соответствие инструкции

| Требование | Результат |
| --- | --- |
| Manifest версии 1, стабильный id, локальные пути и размеры | Проверяются `validate_character.py`; id `arkady` |
| Цельная собственная личность, интересы, реакции и речь | В `persona.md`; оба словаря и примеры включены текстом |
| Отдельные канон и речевой контракт | Есть; намерение, outcome и квитанция доставки различаются |
| Стартовые места, предметы и самостоятельные NPC | 8 сущностей; новые бытовые декорации отмечены в README |
| Исходный импорт без наследования Гарика | Проверен на временном пустом мире |
| Импорт рядом с Гариком | Проверен на временном мире; его канон и места сохраняются |
| Изоляция знания, личных дел и world_note | Проверена; чужая приватная запись не попадает другому участнику |
| Собственный цикл Аркадия | Проверен с подставным backend и точным текстом локального поста |
| Перезапуск и продолжение дела | Проверены; повторный импорт не стирает результат осмотра и незавершённый ремонт |
| Реальная речь на новых многоходовых ситуациях | Требует ограниченного модельного прогона и оценки автора |
| Портрет и фотографии Аркадия | Референс не задан; подключение к фото-адаптеру не выполнено |
| Два живых героя, доставка между ними и Telegram | Требуют доработки хоста; регистрация пакета этого не реализует |

Технические проверки не оценивают художественное качество и не доказывают
автономную жизнь двух персонажей. Авторские реплики в пакете и ответы
подставного backend не являются результатами настоящей модели.

Результат проверки 16 октября: **351 Python-тест и 30 UI-тестов прошли**,
включая 3 теста поставляемого пакета Аркадия и 6 общих тестов профиля.
Дополнительно прошли 9 проверок сборки публичных промптов, проверка старых
рабочих мест и валидация обоих пакетов — Аркадия и неизменённого шаблона.
Аудит 262 текстовых файлов не обнаружил секретов и запрещённых рабочих
данных. Относительные ссылки новых Markdown-файлов разрешаются; машинных
путей и незаполненных полей шаблона в изменениях нет.

## Воспроизвести проверки

В корне целевого репозитория, Python 3.12 и Node.js:

```sh
python3.12 -m venv .venv
source .venv/bin/activate
mkdir -p .local
python tools/validate_character.py characters/arkady/character.json
python -m unittest discover -s tests -p 'test_character_profile.py'
python -m unittest discover -s tests -p 'test_arkady_profile.py' -v
python -m unittest discover -s tests
node --test tests/*.test.cjs
python tools/check.py
python tools/test_prompt_composition.py
python tools/check_publication.py
git diff --check
```

Для этих проверок достаточно стандартной библиотеки Python; `pip install`
и зависимости embeddings не нужны. Проверки пакета и мира используют
временные данные и не вызывают модель или Telegram. `tools/check.py`
проверяет старые файловые рабочие места, а пакет Аркадия проверяют
отдельный валидатор и `test_arkady_profile.py`.

Папка `.local` нужна двум существующим тестам `test_evaluate_voice.py`:
они создают в ней временные каталоги. На свежем клоне без неё эти тесты
завершаются `FileNotFoundError`. Её создание не подключает живые данные.
На машине переноса обычный `python3` указывает на 3.9.6; использован
доступный Python 3.12 и создано игнорируемое окружение `.venv`.

## Что нужно для настоящего запуска

**Офлайн-пакет уже готов к импорту через CharacterProfile.** Для проверки
формата достаточно команды валидатора выше. Для цикла мира есть собственный
тест с подставным backend. Это доступные сейчас воспроизводимые проверки.

**Для ограниченного модельного прогона** нужны собственное авторизованное
подключение Codex, совместимый CLI и отдельная папка данных под `.local/`
или `.runtime/`. Постоянный транспорт закреплён на
`0.162.0-alpha.17.2` в `persona_runtime/app_server.py`; другую версию сначала
проверяют на совместимость. Настройки подключения и при необходимости
прокси остаются локальными. Живой `world_lab` сейчас требует настроенного
прокси. Ключи или авторизацию другого оператора переносить не требуется.
На машине переноса `codex --version` уже возвращает нужную версию;
авторизация, доступность модели и прокси модельным запросом не проверялись.

Существующие CLI `world_lab` и `channel_life` ещё не выбирают пакет Аркадия:
первый создаёт мир с Гариком и передаёт личность под ключом `garik`,
второй также специализируется на нём. Одной подмены `--persona` недостаточно.
Нужен отдельный вход лаборатории или адаптация CLI, использующая:

```python
profile = CharacterProfile.load("characters/arkady/character.json")
store = WorldStore(data_dir, seed_garik=False)  # новая отдельная папка
profile.install(store)                       # paused, без незавершённых циклов
session = WorldSession(
    store, backend, {profile.actor_id: profile.persona},
    profile.speech_contract, max_calls=12,
    personal_life=True, active_world=True,
    autonomous_posts=True, direct_channel=True,
)
store.pause(False)
cycle = session.prepare(profile.actor_id, minutes=10)
```

Это схема подключения к API ядра, не готовая команда модельного запуска:
`backend`, закрытие ресурсов и конечный цикл выполнения задаёт хост.
Сначала ограничить опыт, сохранить ответы и usage, остановиться при ошибке
без автоматического повтора. Проверить новые ситуации: отказ от опыта,
поправку собеседника, просьбу без мата, обычную заботу, неудачу устройства
и возврат к незавершённому делу после смены темы. Затем автор оценивает голос.
Настоящие вызовы модели в рамках этого переноса не запускались.

**Для отдельного Telegram Аркадия** дополнительно нужны его бот BotFather,
токен вне Git, канал и при необходимости связанное обсуждение, права бота,
отдельные секреты/курсор/данные и свободные локальные порты. До запуска
необходимо передать `actor_id` и пакет в `ChannelLife`, `fresh_start`,
`SocialMemory`, намерения, фото и метаданные жизни. Полный перечень —
[раздел 4 инструкции](adding-character.md#4-до-самостоятельного-telegram-другого-героя).
Готовой команды `start-arkady` в текущем ядре нет.

**Для совместной жизни с Гариком** нужны один владелец WorldStore,
последовательный планировщик с независимыми ожиданиями, внутренняя доставка
реплик с устойчивыми id и квитанциями, отдельные личные памяти и Telegram-
подключения. Общие места и канон знакомства согласуются явно; Гарик остаётся
управляемым героем. Критерии — разделы 5–6 инструкции. Два процесса с разными
базами дают независимые миры, а два владельца одной базы запускать нельзя.
