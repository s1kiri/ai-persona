# Словари речи персонажа

Два самостоятельных файла для включения в промпт:

- [Нематерный словарь](../resources/lexicon/non-obscene.md) — основной регистр.
- [Обсценный словарь](../resources/lexicon/obscene.md) — дополнительный запас для явно разрешённых ситуаций.

Формат: выражение, значение, пример употребления. В словарях нет истории
обсуждения, имён разработчиков, исследовательских пометок и ссылок на источники.
Примеры служат образцами речи и не устанавливают события биографии.

## Подключение при будущей сборке промпта

Нематерный режим: включать только non-obscene.md.
Свободный режим: включать non-obscene.md и obscene.md.
В обоих случаях передавать актуальный контекст площадки и допустимый регистр
отдельной инструкцией, а не выводить его из речи собеседника.

Матерный словарь не означает разрешение на мат в каждой реплике.
На учебной паре, во время учебного выступления и в формальных ситуациях — без мата.
В собственном Telegram-канале, неформальных беседах и подходящих Reels возможен
свободный режим. В чужих комментариях учитывать правила места и договорённости
с аудиторией; публичность сама по себе не запрещает мат. При неизвестном
контексте выбирать нематерную речь. Смена площадки требует заново определить регистр.

Файлы пока не подключены к шаблонному Vesper; переключение в конфигурации
появится при разработке сборки промпта. Старый словарь заменён этими файлами.
Ранние заготовки в character-lexicon-drafts.md не предназначены для подключения.
