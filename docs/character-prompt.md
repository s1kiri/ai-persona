# Промпт Гарика v11

11 октября 2026. По прямому поручению автора личность уплотнена, готовые
диалоги убраны, оба словаря пересмотрены. Канон, внешность и история пса
сохранены. Речь задают отношение, желания, уместность и текущая встреча.
Незаконченное желание не требует отчёта при каждом приветствии.

Для локального общения используется
[контекстная сборка](../resources/character/garik-prompt-contextual.md):
личность и выбранная лексика уже включены. В частном разговоре мат допустим,
но не обязателен; формальная и неизвестная обстановка без мата. Исполнитель
сохраняет просьбу человека говорить без мата до ясной новой договорённости.
Самостоятельный юмор не сводится к ругани.

## Сборки

| Регистр | Содержимое |
| --- | --- |
| auto | Личность, 27 нематерных и 15 матерных выражений, правила контекста |
| non-obscene | Личность, полный нематерный словарь, принципы чистой речи |
| free | Личность, оба словаря, принципы свободной речи |
| non-obscene-chat / free-chat | Компактная лексика, встреча и соответствующие принципы |

Все [старые экспорты](../resources/character/README.md) сохранены и пересобраны.
Файл копируется целиком: ссылок на словарь недостаточно. Примеры внутри
словарей объясняют выражения, готовых диалогов для повторения нет.
Локальная проверка не гарантирует отсутствие усечения в другом чате.

[PERSONA.md](../agent/garik/PERSONA.md) задаёт постоянную личность.
[CHAT_SCENE.md](../agent/garik/CHAT_SCENE.md) — встреча без обязательного занятия
для старых чатовых экспортов; в рабочую сборку auto/free/non-obscene не входит.
Реальное состояние, память и дела приходят из исполнителя.

Сборщик tools/compose_persona.py читает [prompt.json](../agent/garik/prompt.json).
Строка в files включает целый файл; path/expressions выбирают выражения
с их значениями и примерами. Пропавшие файлы и выражения дают ошибку.
Старый default_register=non-obscene сохранён для совместимости сборщика;
интерактивный исполнитель выбирает auto явно. Vesper не изменён.

Пересборка и проверка не вызывают модель:

```sh
python3 tools/compose_persona.py garik --register auto > resources/character/garik-prompt-contextual.md
python3 tools/compose_persona.py garik --register free-chat > resources/character/garik-prompt-chat.md
python3 tools/compose_persona.py garik --register non-obscene-chat > resources/character/garik-prompt-chat-non-obscene.md
python3 tools/compose_persona.py garik --register free > resources/character/garik-prompt-full.md
python3 tools/compose_persona.py garik --register non-obscene > resources/character/garik-prompt-non-obscene.md
python3 tools/check.py
python3 tools/test_prompt_composition.py
```

## Проверка поведения

[Новый разбор](character-test-2026-10-11.md) отделяет фактические ответы,
синтетические тесты и ещё не доказанные свойства. Девять тестов сборки
проверяют содержимое и актуальность файлов, а не качество юмора.
Исторические результаты v9–v10 сохранены
[отдельно](character-test-coherence-2026-10-08.md).
Промпт не отменяет обязательные правила среды и сам по себе не реализует
память, доставку, настоящий поиск, автономность или озвучку.
