# Карта кода

Актуально15 октября2026. Это навигация, не промпт модели.

| Файл/папка | Ответственность |
| --- | --- |
| `persona_runtime/character_profile.py` | Пакет личности/канона/среды, ограничение путей, атомарный импорт |
| `characters/_template/` | Авторские заготовки нового героя, не готовая личность |
| `tools/validate_character.py` | Проверка пакета на временном пустом мире, без модели и сети |
| `persona_runtime/world.py` | SQLite, actor_view, транзакции, этапы WorldSession, источники и восстановление |
| `world_protocol.py` | Закрытые схемы, проверки состояния, времени, знания и ссылок |
| `world_prompts.py` / `world_hooks.py` | Раздельные роли мира/героя, планы NPC и доступные затравки |
| `world_intent.py` / `world_threads.py` | Дословный перенос намерения, прерванные действия и продолжения историй |
| `world_backend.py` | Ограниченный Codex app-server для роли, отдельный нативный поиск |
| `channel_life.py` | Один живой герой: время, ожидание, Telegram-заходы, фото и доставка |
| `channel_social.py` | Посты отдельно от комментариев, источники, читатели, намерения и реакции |
| `telegram.py` / `telegram_setup.py` | Bot API, привязка канала/обсуждения, cursor, once-only отправка, localhost-настройка |
| `world_photo.py` / `photo_case.py` | Добровольный выбор фото и проверяемый автономный кейс |
| `world_image_backend.py` / `world_media.py` | Нативная генерация и референсы участника/сущности |
| `world_lab.py` / `world_night.py` | Пульт мира и ограниченные лабораторные прогоны |
| `world_panel/` / `telegram_panel/` | Интерфейсы наблюдения/управления, буквальный вывод пользовательского текста |
| `engine.py` / `background.py` / `daemon.py` | Старый отдельный личный чат, события, занятия, фон и отмена ответов |
| `store.py` / `memory.py` / `embedding.py` | Память/поиск личного чата; необязательные зависимости для embeddings |
| `app_server.py` / `codex.py` / `child_guard.py` | Процессы Codex, ограничение версии, контекста и инструментов |
| `proxy.py` | Необязательный локальный SOCKS5/CONNECT, секрет в macOS Keychain |
| `tools/compose_persona.py` | Сборка публичного Гарика v11 и речевых регистров |
| `tools/check_publication.py` | Проверка tracked source на локальные данные и похожие на ключи строки |
| `tests/` | Офлайн-модель, подставной Bot API, временные БД, UI-контроллеры |
| `agent/` | Исходный файловый шаблон, неизменённый Vesper и публичный Гарик |
| `resources/` | Канон, лексика, утверждённый портрет и исторические пробы |
| `.local/` / `.runtime/` | Рабочие данные и секреты оператора; не часть репозитория |

В названиях строк с сокращёнными путями подразумевается `persona_runtime/`.
Если ищешь реальный вызов/принятие состояния, начни с `WorldSession.step()`,
`WorldStore.complete()` и `ChannelLife.tick_social()`. Для второго героя —
[конкретные точки доработки](adding-character.md#4-до-самостоятельного-telegram-другого-героя).

`agent/scripts/` и `tools/compose_session.py` принадлежат файловой основе
Vesper, не текущей модели мира. Сборщик публичных промптов не переносит
приватный кандидат живого канала автоматически.
