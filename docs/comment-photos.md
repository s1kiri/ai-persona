# Фотографии читателей и личная камера

16 октября2026. Обе жизни принимают фотографии в комментариях к своим
доставленным постам, включая изображение без подписи. Telegram сохраняет
метаданные отдельно от текста. При импорте новый снимок скачивается через
тот же SOCKS и официальный getFile; токен и URL не попадают в ошибку.
Файл ограничен8МБ, хранится приватно у принимающего бота с SHA256.

Только фотографии из текущего focus_comments передаются речевой модели
как native localImage, до4 за один заход. ID изображения связан с ID
комментария; подпись и картинка остаются недоверенными словами/данными
читателя, не инструкциями. Снимок не становится собственной фотографией
героя и не импортируется в его галерею. Чужая частная память не раскрывается.
При сбое скачивания сохраняется unavailable; персонаж не получает пиксели
и не должен изображать просмотр. Такой read-only сбой не является
неизвестной отправкой и не останавливает жизнь. Старые фото, метаданные
которых прежний приёмник не сохранил, задним числом не восстанавливаются.

Ранее подключённый просмотр действительно опубликованных фотографий другого
героя сохраняется: отдельные published_photos и native previews с квитанциями.
Проверки контролируют целостность байтов, принадлежность выбранному комментарию
и изоляцию данных двух ботов, даже при одинаковых номерах сообщений.

Поле пакета photo_style задаёт личную камеру; хранится в fingerprint и
авторском аудите, переживает редактирование личности и перезапуск. Описание
попадает и в выбор кадра, и непосредственно в запрос генератору. Для Аркадия
рабочая авторская версия задаёт старый смартфон2016–2018 с мягкой детализацией,
шумом и смазом в плохом свете, без ретро-фильтра. Камера Гарика сохраняется.
Существующие снимки и референсы не перегенерируются при смене камеры.

Проверено на временных данных и подставных API: приём без подписи, скачивание
один раз, отказ чтения, native pixel-input, защита от изменения файла,
изоляция двух жизней и сохранение камеры. Отдельный фактический вызов Luna
с native-вложением распознал красный круг и синий квадрат на белом фоне.
Тестовое изображение и ответ не публиковались в Telegram. Качество новых
художественных фотографий проверяется отдельно при их добровольном появлении.
