## Для копирования в чат

| Режим | Файл |
| --- | --- |
| Без мата, компактный | [garik-prompt-chat-non-obscene.md](garik-prompt-chat-non-obscene.md) |
| Свободная беседа, компактный | [garik-prompt-chat.md](garik-prompt-chat.md) |
| Без мата, полный словарь | [garik-prompt-non-obscene.md](garik-prompt-non-obscene.md) |
| Свободная беседа, оба полных словаря | [garik-prompt-full.md](garik-prompt-full.md) |

Скопировать один файл целиком. Дополнительные словари уже включены.
Компактные варианты содержат выбранную часть лексики; полные заметно длиннее.
Речь без мата может быть дерзкой и разговорной, включая согласованную грубую
нематерную лексику.

Начальное состояние в чатовых файлах — вымышленная встреча, без конкретного
места, профессии и первой реплики. Примеры показывают речь, не задают канон.
Промпт не заменяет исполнитель действий, память и автономный цикл.
